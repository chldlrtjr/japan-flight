# 🇯🇵 일본특가모아 (JapanFlight) - 일본 항공권 특가 & 프로모션 전문 웹 플랫폼

한국-일본 전 노선(도쿄, 오사카, 후쿠오카, 삿포로, 오키나와, 소도시 온천 노선 등)의 **공식 항공사 특가 프로모션과 실시간 특가 보도자료**를 100% 모아보고 비교할 수 있는 전문 웹 플랫폼입니다.

---

## 🌟 주요 특징

1. **🇯🇵 100% 한일 노선 전용 특화 (일본 국내선 배제)**
   - 동남아, 유럽, 미주 및 **일본 국내 이동선(도쿄-삿포로, 고베-후쿠오카 등 일본 국내선) 전면 배제**
   - 오직 한국 출발 일본행(도쿄/나리타/하네다, 오사카/간사이, 후쿠오카/규슈, 삿포로/홋카이도, 오키나와, 마쓰야마/가고시마/시즈오카/다카마쓰 등 소도시) 항공권만 수집

2. **한일 노선 취항 양국 항공사 전체 라인업 통합**
   - **🇯🇵 일본 국적 항공사 (한일 국제선 운항사)**:
     - **대형 항공사(FSC)**: 일본항공 (JAL), 전일본공수 (ANA)
     - **저비용 항공사(LCC)**: 피치항공 (Peach), 집에어 (ZIPAIR)
   - **🇰🇷 국내 항공사(한일 노선)**: 대한항공, 아시아나항공, 제주항공, 진에어, 티웨이항공, 이스타항공, 에어서울, 에어부산, 에어프레미아, 에어로케이, 파라타항공

3. **한국-일본 직항 31개 취항 도시 전 노선 원클릭 필터**
   - 대도시: 도쿄 (나리타/하네다), 오사카 (간사이), 후쿠오카, 삿포로 (신치토세), 나고야 (주부), 오키나와 (나하)
   - 규슈 권역: 기타큐슈, 구마모토, 가고시마, 오이타, 사가, 나가사키, 미야자키
   - 시코쿠·주고쿠 권역: 마쓰야마, 다카마쓰, 히로시마, 요나고(돗토리), 오카야마, 도쿠시마, 우베(야마구치)
   - 주부·호쿠리쿠·도호쿠·간토: 시즈오카, 고마쓰(가나자와), 센다이, 아오모리, 니가타, 도야마, 고베, 이바라키
   - 홋카이도·도서: 아사히카와, 하코다테, 미야코지마(시모지지마)

4. **📰 일본 특가 보도자료 피드 & 동일 내용 묶어보기 (클러스터링)**
   - 언론사에 배포되는 최신 일본 항공권 할인/특가 보도자료 실시간 수집
   - 여러 언론사에서 동일하게 보도된 기사를 하나로 묶어 대표 기사와 함께 아코디언으로 모아보기 제공

## 🚀 실행 방법

```bash
cd web
npm run dev
# 또는
# npm run start
```
- 브라우저 접속: `http://localhost:3000`

## 🔄 크롤러 및 특가 자동 갱신
```bash
# 전체 항공사 및 뉴스 크롤러 수동 실행
python crawler/runner.py

# 🛑 종료/마감된 특가 검사 및 피드에서 즉시 내리기
python scripts/check_expired.py

# 웹페이지 링크 실시간 생존 여부까지 검사하여 내리기
python scripts/check_expired.py --live

# 만료된 특가 영구 삭제 모드
python scripts/check_expired.py --purge
```
