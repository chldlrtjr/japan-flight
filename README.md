# ✈️ 항공특가모아 (Japan & New Zealand Flight Deals) - 일본 & 뉴질랜드 항공권 특가 전문 웹 플랫폼

한국-일본 전 노선(도쿄, 오사카, 후쿠오카, 삿포로 등 31개 도시) 및 **한국-뉴질랜드(오클랜드 직항, 크라이스트처치, 퀸스타운, 웰링턴 등) 공식 항공사 특가 프로모션과 실시간 특가 보도자료**를 100% 모아보고 비교할 수 있는 전문 웹 플랫폼입니다.

---

## 🌟 주요 특징

1. **🇯🇵 한일 노선 + 🇳🇿 뉴질랜드 국제선 특화**
   - 불필요한 국내선 이동은 배제하고, 한국 출발 일본행(31개 도시) 및 뉴질랜드행(오클랜드, 퀸스타운 등) 공식 특가만 집중 선별 수집
   - **뉴질랜드 주요 취항사 통합**: 에어뉴질랜드(국적기 공식 특가), 대한항공(유일 직항 최저가), 중국남방항공(광저우 경유 가성비 특가) 등

2. **취항 양국 항공사 전체 라인업 통합**
   - **🇳🇿 뉴질랜드 노선**: 에어뉴질랜드 (Air New Zealand), 대한항공, 중국남방항공
   - **🇯🇵 일본 국적 항공사**: 일본항공 (JAL), 전일본공수 (ANA), 피치항공 (Peach), 집에어 (ZIPAIR)
   - **🇰🇷 국내 항공사**: 대한항공, 아시아나항공, 제주항공, 진에어, 티웨이항공, 이스타항공, 에어서울, 에어부산, 에어프레미아, 에어로케이, 파라타항공

3. **원클릭 지역 및 도시 필터**
   - `[ 🌏 전체 특가 | 🇯🇵 일본 노선 (31개 도시) | 🇳🇿 뉴질랜드 노선 (오클랜드 등) ]` 국가별 원클릭 필터링
   - 뉴질랜드: 오클랜드, 크라이스트처치, 퀸스타운, 웰링턴 도시별 맞춤 필터 지원

4. **📰 실시간 특가 보도자료 피드 & 동일 내용 묶어보기 (클러스터링)**
   - 언론사에 배포되는 최신 일본 & 뉴질랜드 항공권 할인/특가 보도자료 실시간 수집
   - 여러 언론사에서 동일하게 보도된 기사를 하나로 묶어 대표 기사와 함께 아코디언으로 모아보기 제공

## 🚀 실행 방법

```bash
cd web
npm run dev
# 또는
# npm run start
```
- 브라우저 접속: `http://localhost:3000`

## 🔄 크롤러 및 특가 자동 갱신
```bash
# 전체 항공사 및 뉴스 크롤러 수동 실행
python crawler/runner.py

# 🛑 종료/마감된 특가 검사 및 피드에서 즉시 내리기
python scripts/check_expired.py

# 웹페이지 링크 실시간 생존 여부까지 검사하여 내리기
python scripts/check_expired.py --live
```
